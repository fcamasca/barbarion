# Imágenes de demostración

Esta carpeta está reservada para capturas reales y reproducibles de Barbarion.

Capturas recomendadas:

- salida de `barbarion ask` con evidencia y citas;
- salida de `barbarion impact` sobre un identificador sanitizado;
- archivos Markdown generados por `barbarion spec create`.

No agregar capturas con nombres de sistemas internos, rutas personales, datos privados ni dominios no sanitizados.
