# Referencias públicas

Esta carpeta está reservada para material técnico complementario que pueda publicarse de forma segura: ejemplos sanitizados, comparativas, glosarios o fuentes que ayuden a comprender las decisiones del proyecto.

No deben incluirse:

- nombres de sistemas, módulos o dominios internos;
- código, rutas, objetos de base de datos o datos de una organización;
- credenciales, endpoints o configuraciones privadas;
- documentos históricos que no hayan pasado una revisión de publicación.

Los documentos maestros de Barbarion se encuentran en la carpeta [`docs/`](../).
